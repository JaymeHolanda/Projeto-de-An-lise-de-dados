# Projeto de Análise de Dados de Vendas do Setor de Eletrônicos

## Sobre o Projeto

📊 Acabei de gerar um dataset com mais de 100.000 linhas de dados de vendas usando Python!

Este é o primeiro passo de um projeto que tem como objetivo criar um dashboard interativo, trazendo insights estratégicos para empresas do setor de eletrônicos, como KaBuM!, Terabyte e Pichau, simulando cenários realistas de vendas.

## Estrutura do Dataset

O arquivo `dados_vendas.csv` contém as seguintes colunas:

- **ID da Venda**
- **Data da Venda**
- **Preço**
- **Preço Original**
- **Desconto Aplicado**
- **Produto**
- **Categoria**
- **Marca**
- **Canal de Venda**
- **Região**
- **Nome do Funcionário**
- **Quantidade de Vendas**
- **Quantidade em Estoque**
- **Avaliação**

Essas informações permitem simular o ambiente de vendas e estoque de uma empresa do setor, possibilitando análises detalhadas.

## Objetivo

O objetivo do projeto é transformar dados brutos em decisões estratégicas. Com um dashboard bem estruturado, será possível:

- Identificar padrões de vendas
- Entender o desempenho por categoria, produto ou funcionário
- Otimizar o estoque
- Prever tendências de mercado

## Tecnologias Utilizadas

- **Python**: Para geração e estruturação do dataset
- **Tableau** ou **Power BI**: Para visualização e análise dos dados (próximas etapas)
